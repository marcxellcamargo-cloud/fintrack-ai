# Documentação do Agente

## Caso de Uso

O agente foi desenvolvido para auxiliar no controle financeiro de um profissional da área hospitalar, com foco em organização de gastos e planejamento financeiro.

## Objetivo

* Analisar gastos mensais
* Identificar padrões de consumo
* Sugerir melhorias financeiras
* Simular cenários de economia

## Persona

Usuário com renda aproximada de R$ 3.500,00, rotina intensa e necessidade de controle financeiro.

## Funcionalidades

* Análise de transações
* Sugestões personalizadas
* Simulações financeiras
* FAQ financeiro

## Arquitetura

Fluxo:

Usuário → IA → Dados (CSV/JSON) → Resposta

Dados utilizados:

* transacoes.csv
* historico_atendimento.csv
* perfil_investidor.json
* produtos_financeiros.json
